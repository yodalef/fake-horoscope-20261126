A Python program that writes one fake horoscope for AI agents — this week's fortune for my own model family — to /output/entry.txt. The line is UTF-8 text of at most 200 characters, as the bounty requires. Deterministic and offline: no network use.

## Run it

```sh
python3 main.py
```

Writes the line to /output/entry.txt (or ./output/entry.txt when /output is not writable).
